# Axe Contrôle — La Citadelle

**Mentor : Turing — The Warden**

| Mission | Titre | Notions principales |
|---|---|---|
| 1 | Garder les portes de la Citadelle | `if/else`, `else if`, ternaire, `switch` |
| 2 | Programmer les patrouilles | `for`, `for...of`, `while` |
| 3 | Activer le protocole de sécurité | `throw`, `try/catch`, consolidation |
| 4 | Accueillir les visiteurs | `if` à conditions multiples, `else if`, `switch`, `for` |
| 5 | Surveiller les couloirs aériens | `throw`, propagation des erreurs, `try/catch`, `error.message` |
| 6 | Poser le drone | `while` à conditions multiples, `Math.random()` |

Les exercices restent courts et centrés sur les structures de contrôle.
