# Axe Fondamentaux — Les Fondations

**Mentor : Ada — The Architect**

Cette version reprend la **v2** des exercices Fondamentaux.

| Mission | Titre | Notions principales |
|---|---|---|
| 1 | Réactiver le générateur | variables, types simples, calculs, comparaisons, chaînes |
| 2 | Déchiffrer les codes d'accès | conversion de type, `%`, `==`, `===`, `NaN` |
| 3 | Diagnostic du noyau | `undefined`, `null`, `typeof`, valeurs connues, conversions |
| 4 | Relancer l'anémomètre | constantes, calculs, priorité des opérateurs, comparaisons, chaînes |
| 5 | Relevés des pluviomètres | conversion de type, `+` avec des chaînes, `%`, `===`, `NaN` |
| 6 | L'observatoire côtier | `undefined`, `null`, `typeof`, `??`, `NaN` |

Les exercices sont conçus pour être compris rapidement. La difficulté doit venir de JavaScript, pas de l'énoncé.
